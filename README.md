# Ассистент урока (открытый ИИ-помощник)

Десктоп-приложение: постоянно слушает микрофон и ведёт живую расшифровку (RU/EN),
но **отвечает только когда ты нажимаешь горячую клавишу**. Окно видимое — оно
намеренно НЕ скрывается при демонстрации экрана.

## Что нужно
- Node.js 18+
- Python 3.10+
- Ключ Claude API — https://console.anthropic.com/

## Установка
```bash
npm install
python3 -m venv .venv
source .venv/bin/activate
pip install -r stt/requirements.txt
```

## Запуск
```bash
source .venv/bin/activate      # чтобы приложение нашло Python с faster-whisper
npm start
```
Если Python не из venv, укажи путь явно: `PYTHON_BIN=/путь/к/python npm start`.

1. Введи тему урока и ключ Claude API → «Начать урок».
2. Приложение слушает и показывает расшифровку.
3. Нажми **Ctrl/⌘ + Shift + Enter** — ассистент ответит на последний вопрос.
4. Внизу можно ввести вопрос вручную.

## Заметки
- Первый запуск скачивает модель Whisper (`small`, ~460 МБ). Для точности можно
  поставить `medium`/`large-v3` в `stt/stt_server.py`.
- macOS спросит доступ к микрофону — разреши.
- Порог громкости/тишины `ENERGY_THRESHOLD` в `stt/stt_server.py` подстраивается под микрофон.
- Ответы показываются в видимом окне; ничего не прячется от демонстрации экрана — так задумано.
