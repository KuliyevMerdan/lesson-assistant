# CLAUDE.md

Проектная памятка для Claude Code. Держи в актуальном состоянии при изменениях.

## Что это

**Ассистент урока** — десктоп-приложение в помощь преподавателю на живых онлайн-уроках.
Постоянно слушает микрофон, ведёт живую расшифровку (RU/EN) и — **только по нажатию
горячей клавиши** — просит Claude развёрнуто ответить на последний вопрос.

## Принцип, который нельзя нарушать

Окно ассистента **намеренно видимо во время демонстрации экрана**. `setContentProtection`
осознанно НЕ используется. Инструмент задуман как открытый: преподаватель и другие
участники видят его на экране.

Не добавляй: скрытие от захвата экрана, «невидимые» оверлеи, стелс-режимы, а также
автоматические ответы без явного действия человека. Ответ появляется только по горячей
клавише (human-in-the-loop) — это часть замысла, а не ограничение реализации.

## Стек

- **Electron** (`main.js` + `preload.js` + renderer) — окно, глобальная горячая клавиша, UI
- **Python + faster-whisper** — локальный STT-сайдкар (офлайн, автоопределение RU/EN)
- **Claude API** (`@anthropic-ai/sdk`), модель `claude-sonnet-5`

## Как устроен поток данных

1. `stt/stt_server.py` захватывает микрофон (sounddevice, 16 кГц), режет речь на фразы по
   паузам (энергетический VAD), распознаёт каждую фразу faster-whisper и печатает в stdout
   JSON-строки: `{"type":"line","text":...,"lang":...}`.
2. `main.js` запускает этот сайдкар, читает stdout, дописывает в кольцевой буфер `transcript`
   (лимит 4000 симв.) и пересылает каждую строку в renderer для живого отображения.
3. Глобальная клавиша **Ctrl/⌘ + Shift + Enter** → `main.js` отправляет транскрипт + тему в
   Claude → присылает ответ в renderer.
4. Поле ручного ввода в UI → IPC `ask-manual` → Claude → ответ.

## Файлы

- `main.js` — Electron main: окно, разрешение на микрофон, глобальный шорткат, запуск STT и
  IPC, вызовы Claude. Константы конфигурации сверху: `MODEL`, `ANSWER_HOTKEY`, `TRANSCRIPT_CAP`.
- `preload.js` — безопасный мост (`contextBridge`): `startSession`, `askManual`, `onSttLine`,
  `onAnswer`, `onStatus`.
- `index.html` / `renderer.js` / `styles.css` — интерфейс: экран запуска (тема + ключ API) и
  основной экран (расшифровка, ответ, ручной ввод).
- `stt/stt_server.py` — локальный STT. Настройки: `ENERGY_THRESHOLD` (чувствительность
  микрофона), `SILENCE_HANG`, `MIN_SPEECH`, `MODEL_SIZE` (`small`/`medium`/`large-v3`).
- `stt/requirements.txt` — faster-whisper, sounddevice, numpy.

## Что где крутить

- Горячая клавиша — `ANSWER_HOTKEY` в `main.js`.
- Модель ответов — `MODEL` в `main.js` (`claude-sonnet-5`).
- Точность vs скорость распознавания — `MODEL_SIZE` в `stt/stt_server.py`.
- Чувствительность микрофона — `ENERGY_THRESHOLD` в `stt/stt_server.py`.
- Ключ API — вводится в окне запуска (только на сессию, на диск не пишется) или через
  переменную окружения `ANTHROPIC_API_KEY`.

## Запуск (обычный терминал пользователя)

Node установлен через **nvm** (default — v20), в обычном интерактивном терминале nvm
подгружается сам:

```bash
npm install
python3 -m venv .venv && source .venv/bin/activate && pip install -r stt/requirements.txt
npm start
```

## Окружение для изолированных сессий Claude (ВАЖНО)

В песочнице Claude Code `HOME` подменяется на путь Parallel Spaces, поэтому nvm НЕ
подгружается автоматически и `node`/`npm` отсутствуют в PATH — **но Node установлен**.
Используй абсолютный путь nvm:

```bash
export PATH="/Users/merdan/.nvm/versions/node/v24.14.1/bin:$PATH"
```

Доступные версии в `/Users/merdan/.nvm/versions/node/`: `v20.19.5`, `v22.0.0`, `v24.14.1`.
Некоторым командам (Spotlight/`find`, сеть для `npm install`) нужна Bash с отключённой
песочницей. Системный `python3` — 3.14: STT-зависимости успешно ставятся на 3.14
(faster-whisper 1.2.1, ctranslate2 4.8.1, onnxruntime 1.29.0, numpy 2.5.2) — фолбэк на 3.12 не нужен.
